# Chapter 9: Teaching Plan for New Developers

This documentation is designed to help a beginner learn fullstack web development using this project as a sample.

## Suggested learning sequence

### Week 1: Understand the basics

Study these chapters first:

- Chapter 1: Introduction
- Chapter 2: Architecture overview
- Chapter 3: Frontend layer
- Chapter 4: Backend layer

### Week 2: Learn data and logic

Focus on:

- Chapter 5: Database and models
- Chapter 6: Testing and debugging

### Week 3: Learn collaboration and deployment basics

Study:

- Chapter 7: Git and GitHub
- Chapter 8: Running the app

## How to teach others with this project

When teaching someone:

1. Start by showing the project structure.
2. Explain the frontend and backend separately.
3. Walk through one CRUD flow such as creating a flat.
4. Show how the data moves from React to FastAPI to SQLite.
5. Demonstrate how to test and debug the app.
6. Show how to commit and push code to GitHub.

## Suggested hands-on exercises

### Exercise 1: Add a new page

Create a new frontend page for dues or expenses.

### Exercise 2: Add a new API route

Add an endpoint to fetch expenses by month.

### Exercise 3: Add a new model

Create a model for visitor records or maintenance requests.

### Exercise 4: Write a test

Write a test to verify that a new expense can be created through the API.

## Best practices to teach

- Keep examples simple and clear.
- Show one concept at a time.
- Encourage learners to read the code and explain it out loud.
- Ask them to make small changes and observe the result.
- Repeat important concepts with real examples.

## Summary

This project is a practical teaching tool because it covers the major parts of a fullstack app without being too large.

By working through these chapters, a new developer can build confidence and understand how modern web applications are put together.
