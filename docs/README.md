## How to use this guide

- Read the chapters in order.
- Try the code examples in the project.
- Run the app locally while reading.
- Make changes on your own and observe the results.

## Suggested learning approach

- Start with the architecture chapter.
- Then move to frontend and backend concepts.
- Practice with the app and write your own small features.
- Use Git to save your progress.
