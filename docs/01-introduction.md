# Chapter 1: Introduction to the Apartment HOA Fullstack App

Welcome to this learning project. The goal of this application is to help you understand how a modern fullstack web app is structured using:

- Frontend: React + Vite + Tailwind CSS
- Backend: FastAPI + SQLAlchemy + SQLite
- Version control: Git and GitHub

This project is a small but realistic apartment HOA management system. It allows you to manage:

- Flats
- Residents
- Parking spots
- HOA committees
- Monthly dues
- Expenses

By studying this project, you will learn how a fullstack application is split into layers, how data flows between them, and how to run, test, and deploy the app.

## What you will learn in this project

By the end of this course, you should be able to:

1. Understand the role of frontend, backend, and database layers.
2. Create CRUD APIs with FastAPI.
3. Connect a React UI to a backend API using Axios.
4. Use SQLAlchemy models and SQLite for persistence.
5. Version your project with Git and publish it on GitHub.
6. Run tests and build the application locally.

## Project structure

The repository contains these main folders:

- frontend/: React app UI
- backend/: FastAPI backend API and database logic
- docs/: Learning documentation

## Why this project is good for learning

This project is small enough to understand quickly, but it includes enough real-world features to teach important concepts such as:

- REST APIs
- CRUD operations
- Database modeling
- Relationship mapping between entities
- Frontend form handling
- API integration
- Basic testing

## Example of the app in one sentence

This app lets a housing association manage apartments, residents, parking, committee members, dues, and expenses from one system.
